# Dataset de dígitos 28x28
- Archivo: mnist10k.npz (arreglos X de 10000x784 en uint8, 0 a 255, y etiquetas y de 0 a 9)
- Origen: paquete npm "mnist" 1.1.0 (Juan Cazala, licencia MIT), que incluye 10,000 imágenes tomadas de MNIST
- Dataset original a citar: LeCun, Y., Cortes, C. y Burges, C. J. C., "The MNIST database of handwritten digits"
- Conteo por dígito: 0:1001 1:1127 2:991 3:1032 4:980 5:863 6:1014 7:1070 8:944 9:978
